# 作业02：项目选题与功能规划

## 项目选题

**最终选题**：社区生鲜团购/配送系统

**确定过程**：
在对比了宠物医院、购物系统、健身房等多个示例后，我发现社区生鲜团购具备更天然的业务闭环，且非常契合微服务架构的演进。它涉及多类角色（居民、团长、供应商、管理员），业务链路长（下单-支付-分拣-核销），能充分训练后续的数据库持久化、服务拆分、消息通知与事务处理能力。此外，该场景贴近日常生活，需求明确，且难度适中，不会因为过于复杂的高并发设计而偏离课程核心目标。

## 功能规划

**本周完成内容**：
本周完成了社区生鲜团购系统的功能规划。具体包括：明确了四类用户角色（居民、团长、供应商、管理员）及其核心需求；划分了六大功能模块（认证、商品、订单、支付、核销、消息）；梳理了从浏览商品到下单支付、供应商发货、团长分拣核销的核心业务流程；界定了当前项目范围（暂不涉及复杂推荐和秒杀）；并规划了后续向微服务架构演进的明确路径。

**后续计划**：
接下来将进行数据库设计与实体建模，开始搭建 Spring Boot 单体工程骨架，实现基础的用户认证与商品管理接口。
