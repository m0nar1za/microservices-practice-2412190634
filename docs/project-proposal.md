# 项目提案

## 项目名称
社区生鲜团购/配送系统

## 目标用户
- 居民（买家）：浏览商品、参与团购、下单支付、凭码自提。
- 团长：管理自提点、分拣商品、核销提货码、申请佣金。
- 供应商：管理商品、更新库存、处理供货订单。
- 平台管理员：审核资质、处理售后、查看报表。

## 优先实现业务场景
优先实现“居民浏览商品 -> 下单支付 -> 供应商发货 -> 团长分拣核销”的完整闭环。

## 两个核心模型
1. 用户（User）
2. 订单（Order）

## Week 04 业务建模

### 本周核心业务流程
居民选择商品并提交订单 -> 系统检查商品库存 -> 扣减库存并生成订单 -> 返回下单成功信息。

### 核心业务实体及关系
1. **商品（Product）**：包含商品ID、名称、价格、库存。
2. **订单（Order）**：包含订单ID、关联的商品ID、购买数量、订单总价、下单时间。
- **关系**：一个订单关联一个商品（多对一关系）。

### Service 业务规则
**库存校验规则**：用户下单时，如果购买数量大于商品当前库存，或者库存不足，必须抛出异常阻止下单。
